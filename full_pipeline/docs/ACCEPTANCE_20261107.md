## 实际审核、修复与独立数值检查

初次静态结构/字段检查通过后，两个实验分别有2个代码实现被逐函数审核拒绝。Fish 微观输出没有正确保留主体索引，中观输出把随机运行 ID 用作特征名。Covasim 微观函数把主体量擅自取均值，中观函数把未知感染状态填为未感染。拒绝记录绑定原代码与定义双哈希，原始响应仍保留。这些代码没有执行。

只重新生成对应的4个代码任务，保留现象、变量、其他已审核代码和独立关系阶段。修复响应再次逐函数阅读，审核身份明确为 **Codex 助手审核，非人工审批**。每个函数记录数学定义、观测单位、时间、字段、操作权限的具体结论，再转换为原 trusted_reviewed 格式执行。AST 通过从未被当作自动执行许可或安全沙箱。

修复后6个指标在11个独立运行上共33次执行全部成功，均由原 Trajectory 接口和原本地 Python 子进程实际计算。独立检查器未执行生成代码，而是从真实原始日志重新计算被审核的数学定义，在首/末种子各4个时刻检查全部3个指标：Fish 比较 **16016** 个实际数值，Covasim 比较 **8040** 个实际数值，共48个节点/运行/时间点抽查，全部在 rtol=atol=1e-10 容差内一致。Fish 距离使用独立 KD-tree，碎片化使用 NetworkX 连通分量，伸长率使用对称矩阵特征值；Covasim 使用原始端点集合、状态与计数。脚本仅为验收核对，未进入生产生成流程或预置指标库。抽查不等于对任意输入的形式化证明。

## 统计结果与边界

Fish 最近邻距离仍是逐鱼观测，缺少显式主体选择/向量映射配置，因此 M1 排除该节点，未默认求均值。两个系统量具有足够窗口，进入实际 M2。外部候选父时滞未获得稳定支持，两个 M3 记录为 inconclusive，未训练并宣称不存在的外部关系；宏观节点保留为有效孤立节点。最终自记忆边的权重1来自实际 M2，另有其他受支持历史保存在 lags/evidence 中。

Covasim 微观接触度同样保留逐主体单位；层级感染边比例包含多特征而没有显式层选择。因此两者被 M1 排除，既不擅自平均也不当作独立重复样本。系统计数具有有效动态窗口并完成 M2，自身主要时滞1步通过原确认与校正流程。当前最终图只有自记忆证据。

本次低成本真实图在准入后没有多父节点目标，因而没有执行真实场景的 PID 组合，也没有获得任何外部边支持。不能把这两套结果写成已经验证跨尺度机制或真实场景协同。原第二部分的合成集成测试仍实际训练单来源 GRU、识别已知时滞并计算 XOR 联合关系；其全部回归继续通过。后续正式实验应预先设定有科学含义的主体/层映射及更丰富变量预算，不能根据本轮显著性反复改候选图。

## 复现材料与仍有的限制

每个 internal_audit.zip 包含完整尝试和检查点、真实提示/响应、审核、计算源码、实际指标 Parquet、原始执行日志、真实第二部分模型和证据，附有 SHA256SUMS。大体量原始仿真 Parquet 保留于本机对应实验 internal/simulation，归档中记录其路径与完整哈希，不重复上传 GitHub。归档的绝对路径是原验收机器路径，迁移机器应新建实验或明确记录路径迁移，不能静默修改原始图和哈希。

本轮没有解决“任意自然语言产生新模型”，只支持精确注册的两个模型。一般数学等价和重复定义无法仅由静态文本检查证明。主体/层变量在当前预算下尚需研究者预先声明分析映射；没有在本轮偷偷补上这种科学选择。原 GRU 消融、有限样本块 Bootstrap、MMI 分箱与两两组合的局限仍适用。最终图只表达观测预测信息，不能作为完整结构因果真值。
