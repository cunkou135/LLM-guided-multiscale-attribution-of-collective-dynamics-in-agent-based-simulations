# 模型规格：ODD

## 标准 Schelling（schelling_standard）

**目的。** 观察基于邻居相似性和迁居的居住分布演化，为后续计算空间统计量提供主体轨迹，不以仿真本身证明现实中的因果关系。

**实体、状态和尺度。** 二维离散 Moore 网格，单格最多一个主体；主体有 ID、0/1 群体、格坐标、上一轮结算的满意状态。`width`、`height` 为网格尺寸；`radius` 为邻域半径；`torus` 决定是否环绕。默认 20×20、半径 1、非周期。没有额外环境状态。

**过程与调度。** 每轮先随机打乱全体主体；不满意者迁至全体空格中随机选择的位置，满意者不移动。迁移决定使用上轮统一计算的满意状态，轮内不重新计算；因此行动时邻居数量可能与该状态所依据的数量不同。所有主体行动完后统一计算满意状态。如果全体满意则停止；外部 `steps` 为最大轮数。空格不足的满格初始状态可导致迁移失败，失败被记录而非修改规则。

**满意度。** 在半径内统计已占据邻居总数 `n` 和同类型数 `s`；`n>0` 时相似度为 `s/n`，`n=0` 时为 0；当相似度大于等于 `homophily` 满意。空格不计入分母。默认阈值 0.4。`minority_pc` 是每个已生成主体为类型 1 的概率，默认 0.5；`density` 是每格独立占用的概率，默认 0.8；均在 [0,1]。

**初始化、输入及随机性。** 从给定种子初始化 Mesa 随机数发生器；按 Mesa 网格的单元顺序，对每格独立抽样占用，对占用格独立抽样类型。随后统一计算满意状态并记录 step 0。无外部时变输入。观察与日志不消费随机数。独立重复的种子和配置见 manifest 与 resolved YAML。

**输出。** 默认每轮保存主体坐标、类型、邻居计数和满意度，以及每位主体的一次激活事件。模型汇总是描述性统计；事件中的 `happy_after` 是行动后尚未统一重算的存储状态。

## 扩展 Schelling（schelling_extended，2.0）

这是本文实验自行规定的异质偏好与有限迁居扩展，不是未经修改的 Mesa 官方示例。标准类与其原有测试独立保留，默认正式配置改为扩展版本。默认100×100、最多300轮、非周期、Moore半径1；每格独立以0.85概率占用，已占用格以0.5概率分配群体B，因此实际人口并非固定8500。

初始化时依次抽样占用、群体和个体阈值 theta_i。阈值从均值0.45、标准差0.10的正态分布拒绝抽样，接受区间[0,1]，不进行边界裁剪。全部参数写在YAML；std=0为区间内的退化常数。阈值之后固定。没有已占据邻居时相似度为0，与标准模型基础定义一致。

每轮随机排列全部主体，每位主体根据激活当下的邻居重新判断满意度。满意者保持原位；不满意者枚举Chebyshev距离不超过relocation_radius（默认8）的全部本地空位，非周期边界不越界，周期配置按包裹距离和唯一单元计算。评分先假设原位置已腾空，再统计目标邻居，正确扣除相邻候选位置中原主体的贡献。

存在达到个体阈值的候选时，选择其中同类邻居比例最高者；否则只考虑比当前比例严格更高的候选，并取最高者。同分使用模型随机数随机选择。没有本地空位或没有满意/严格改善候选时保持原位置，分别记录失败原因。策略标识为best_local_satisfactory。每次激活最多搬迁一次。

全部主体行动完后统一更新满意度并保存完整轮状态。全体满意记stable；仍不满意且整轮零迁居记frozen。这里零迁居意味着每个不满意主体已穷举当时所有候选，而全轮状态未变化，因而确实无可行迁居，并非随机试探一次失败。达到预算记max_steps，提前停止不补齐末态。缓存仅维护局部邻居计数和局部坐标集合，迁居后立即更新；不会跳过主体或变更随机顺序。

主体状态新增theta_i。激活事件新增attempted、candidate_count、feasible_count及similarity_before/after。feasible_count表示满意候选数量，若不存在则为严格改善候选数量；reason区分satisfied、local_satisfactory、local_improvement、no_local_vacancy、no_satisfactory_or_improving_location。happy_after为自身行动后的即时满意度，可能因后续邻居行动而与本轮最终快照不同。

## Covasim

**目的与范围。** 通过原生 2.0.0 引擎观察个体疾病状态、分层接触和疫情总量。当前配置属于未历史校准的演示，默认2.0想定为一般城市背景。1.0历史想定及旧运行保持可读，但不表示模型已复现金县。

**实体与状态。** 个体包含 UID、年龄、性别、相对传播/易感性及疾病概率；susceptible/exposed/infectious/symptomatic/severe/critical/tested/diagnosed/recovered/dead/known_contact/quarantined 状态；各状态日期和疾病阶段持续时间，共 40 个原生字段。2.0.0 没有独立 isolated 布尔量，原生诊断状态参与隔离效果计算。不能额外构造该字段为观测事实。

**空间与接触。** 演示使用原生 hybrid 的 h/s/w/c 网络；每天记录各层潜在接触边和原生权重，不将潜在边称为成功接触或实际传播。没有 l 层即没有记录 LTCF 接触。pop_scale=1 和 rescale=false 是当前微观轨迹配置，避免动态重采样使同一 UID 的纵向解释混淆；不是修改原生疾病机制。

**调度。** 原生 Sim.step 顺序为重缩放检查、状态更新、接触更新、输入感染、干预、干预后状态更新、逐层双向传播、汇总和 Analyzer。适配器不重新实现这些决策。平台 step 0 是初始化后、首日之前（simulation_day=-1）；平台 step k 是完成原生 day k-1，故 steps=60 执行 day 0..59。初始种子感染已列入原生 infection_log，其记录时间可能为 day 0，即使在初始快照采集时。到预算结束记 max_steps，不称疫情稳定。

**初始化与干预。** YAML 显式给出人口、初始感染、beta、开始日、种子和 test_prob/contact_tracing/change_beta/clip_edges 对象参数；有效疾病参数的最终校验由固定原生引擎完成。所有示例参数是实验输入，不作为金县人口、病例或校准值。原文基准另见实验脚本。

**观测。** 每个启用采样步记录完整个体与网络；每次成功感染读取 infection_log。每日状态差异产生状态转移事件，date_tested 的变化可识别跨日重复检测。原生未暴露所有未成功的感染尝试或同日多次检测事件，清单明确记缺失。原始字段和模型结构知识不能当作后续 LLM 的新发现。

## 迁移鱼群fish-3.0

采用用户提供collective_motion_lab的原始同步鱼群/鲨鱼引擎，默认2000条鱼、5条鲨鱼、dt=0.08。开放空间、局部排斥优先，对齐与吸引合成；受惊依据步初状态，社会传播同一步不多跳；鲨鱼追逐最近可感知鱼，没有捕获与移除。速度每步按原均值/标准差转换的对数正态分布抽样，转向与噪声规则不变。模型为用户原项目的研究设置，不声称是本平台新发明的群体运动算法。迁移范围、原生哈希与参数映射见FISH_MIGRATION.md。
