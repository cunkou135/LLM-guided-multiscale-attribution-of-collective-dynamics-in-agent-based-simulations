# 模型规格：ODD

## Schelling

**目的。** 观察基于邻居相似性和迁居的居住分布演化，为后续计算空间统计量提供主体轨迹，不以仿真本身证明现实中的因果关系。

**实体、状态和尺度。** 二维离散 Moore 网格，单格最多一个主体；主体有 ID、0/1 群体、格坐标、上一轮结算的满意状态。`width`、`height` 为网格尺寸；`radius` 为邻域半径；`torus` 决定是否环绕。默认 20×20、半径 1、非周期。没有额外环境状态。

**过程与调度。** 每轮先随机打乱全体主体；不满意者迁至全体空格中随机选择的位置，满意者不移动。迁移决定使用上轮统一计算的满意状态，轮内不重新计算；因此行动时邻居数量可能与该状态所依据的数量不同。所有主体行动完后统一计算满意状态。如果全体满意则停止；外部 `steps` 为最大轮数。空格不足的满格初始状态可导致迁移失败，失败被记录而非修改规则。

**满意度。** 在半径内统计已占据邻居总数 `n` 和同类型数 `s`；`n>0` 时相似度为 `s/n`，`n=0` 时为 0；当相似度大于等于 `homophily` 满意。空格不计入分母。默认阈值 0.4。`minority_pc` 是每个已生成主体为类型 1 的概率，默认 0.5；`density` 是每格独立占用的概率，默认 0.8；均在 [0,1]。

**初始化、输入及随机性。** 从给定种子初始化 Mesa 随机数发生器；按 Mesa 网格的单元顺序，对每格独立抽样占用，对占用格独立抽样类型。随后统一计算满意状态并记录 step 0。无外部时变输入。观察与日志不消费随机数。独立重复的种子和配置见 manifest 与 resolved YAML。

**输出。** 默认每轮保存主体坐标、类型、邻居计数和满意度，以及每位主体的一次激活事件。模型汇总是描述性统计；事件中的 `happy_after` 是行动后尚未统一重算的存储状态。

## Deffuant–Weisbuch

**目的。** 观察完全混合、双向妥协的连续意见演化；不添加网络、反向更新、异质置信边界、外部信息或学习。

**实体和尺度。** `population >= 2` 个主体，各持有意见 `x`。默认独立均匀初始化 `uniform_0_1`，实际伪随机数取值 [0,1)。参数 `epsilon ∈ [0,1]`、`mu ∈ [0,0.5]`；mu=0 是无意见变化的边界情况。

**过程与调度。** 基本事件是从全体主体中无放回均匀抽取两个不同主体，事件之间重新抽样。记事件前意见为 `x_i` 和 `x_j`，当且仅当 `abs(x_i-x_j) < epsilon`，同时按 `x_i' = x_i + mu*(x_j-x_i)`、`x_j' = x_j + mu*(x_i-x_j)` 更新；否则原值不变。相等边界不更新。公式保持两者意见和，并将意见维持在初始区间。每个采样步执行配置的 `interactions_per_step` 次基本事件；所有配对尝试均记录。模型运行到 `steps` 上限，不将短期无更新误判为收敛。

**初始化、输入和输出。** 种子决定均匀初值和随机配对。没有时变外部输入。完整事件保存双方 ID、前后意见、差异、阈值、系数、是否接受、增量和原因；状态在初态、指定采样步和末步保存。意见组是后处理定义，必须同时说明距离阈值和观察时刻。
