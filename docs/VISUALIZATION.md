# 交互观察、历史回放与论文图形

从仓库根目录运行`python start.py`选择模型与方式，或直接使用README的ui命令。浏览器访问127.0.0.1:8765；两个场景在同一页面选择，无需重启。页面以Solara组织，Plotly提供缩放、平移与点击；采用5.24.1以兼容Solara现有FigureWidget。Matplotlib负责静态论文图。

## 实时实验

左侧显示实际YAML及模型参数。修改输入后点击“重置并应用”创建新run_id，原运行正常关闭并保留interrupted清单。只修改输入不会影响当前运行。单步执行推进完整一轮或一个原生日；连续运行与暂停控制同一RunSession。界面与无头使用同一仿真核心，显示不调用模型随机数。对自定义规模、边界、偏好截断与干预等完整参数，编辑YAML后点击加载。

扩展Schelling主图呈现100×100实际占用，蓝/橙为两群体，浅灰为空位。工具栏缩放、平移或复位可查看局部。点击已占位置展示主体ID、群体、固定theta_i、当前坐标、满意度及最近迁居步；空位明确标记。可叠加不满意主体、最近若干轮迁入位置和同类邻居比例热力图。右侧初始/最新快照与主图所选历史状态形成对照。下方满意比例与迁居数分面显示，时间标记同步。热力图孤立主体比例为0，空位为空值；这些只用于过程观察。

## Covasim Simulation Mode：真实主体主场景

默认进入主体网络，主图不是统计图或静态传播树。Canvas绘制全部真实UID节点，默认1000人，节点不会抽样。颜色从实际原生字段按死亡、恢复、传染、暴露、易感的优先级读取；infectious是exposed的子集。诊断蓝圈与检疫紫圈是独立叠加属性。顶部显示实际日历日期、原生日和平台步数；初始化为day=-1。

显示坐标只初始化一次并按run_id缓存，先从初始实际家庭边建立家庭组，再用初始学校/工作场所关系计算社会分量内的布局；断开分量按人数分配显示空间，家庭成员添加固定局部偏移。所有布局随机数只来自显示种子，与Covasim随机流独立。坐标没有地理意义，推进日期不重新布局。

右侧家庭、学校、工作场所、社区开关筛选该时点真实接触快照。无向重复接触边仅在显示时去重，原始日志不变；默认最多1400条，按层交错选择，界面明确列出显示数/符合过滤条件的去重数。选中主体的真实接触边优先，必要时仍受显示上限约束。所有1000个主体仍显示；未选节点可减淡。选中后还能显示最近3个已记录步的实际接触虚线。潜在接触不等于成功传播。

新增感染单独读取该实际步的infection_log记录：有来源时显示红色连接、沿边移动的亮点与目标脉冲；无来源事件只有目标状态与脉冲。动画持续时间独立于引擎，绝不补造传播边。感染高亮不受背景潜在接触层开关限制，以免漏掉当日真实传播；颜色状态始终按全部原始字段更新。暂停后模型停在最后完成的完整原生日，正在执行的原生日会先完成。

支持滚轮/按钮缩放、拖动平移、真实节点点击、UID搜索、邻接主体跳转与局部接触显示。节点详情来自当前实际状态，包括年龄、原生sex编码、诊断、检疫、症状、重症和危重状态。它不会把计划中的未来疾病日期当作已发生事实。

统计曲线、局部传播记录、感染环境计数及年龄组成保留在“展开辅助分析”中，关闭时不构建这些图形。Publication Mode是独立的静态图版模式，保留SVG及300/600DPI PNG，重置/切换模型默认回到Simulation Mode。

新显示配置在configs/population.yaml，包括画布最大高度、边上限、脉冲毫秒数、布局种子/迭代数、近期接触窗口。画布依据浏览器高度适配；configs/covasim.yaml的play_interval_seconds仅控制显示节奏，不改变原生日更新规则。前端使用浏览器自带Canvas及既有Solara/Vue，不增加新的仿真框架；NetworkX是Mesa已有依赖，本项目显式声明其显示布局用途。

## 真实界面截图与GIF

“保存网络截图”保存浏览器当前实际Canvas；“记录浏览器演示帧”在每个新显示步保存一帧。输出位于该run_id/ui_capture/，每帧PNG附带run_id、原生日、状态计数、全部节点状态摘要哈希、布局哈希和实际感染事件序号。捕获直接使用实际Canvas像素，既不是Matplotlib重绘，也不是合成示意。录制时请保持界面可见，避免浏览器节流跳帧。

```bash
python -m visualization.population --capture-dir results/<run_id>/ui_capture --start 1 --end 30 --output figures/covasim_agents.gif
```

GIF工具要求至少10个连续原生日的真实浏览器帧、同一run_id及相符PNG哈希；缺帧报错，不插值补造。组装只连接原始截帧并设置播放时长，不生成新状态。完整浏览器检查与本次实际演示材料见验收报告。

## 历史轨迹

输入已有运行目录，点击“打开历史回放”。回放只经Trajectory读取已保存状态，不重新运行引擎。时间轴索引只映射available_steps中的实际时间点，采样间隔不会插值。播放轨迹/下一已记录时点仅改变显示；实时模式的“跟随最新状态”可回到最新保存轮。重置或选择模型返回新实时实验。正式论文分析建议先完成无头运行，再打开其记录。

## Publication Mode

勾选显示论文图版可预览当前真实时间点；点击导出保存SVG、PNG300/600DPI、figure_data.json和figure_manifest.json，位置为本运行figures/step_XXXXXX，页面提供下载。图形设置全部在configs/figures.yaml：7.2英寸宽、4:3或16:9、字体、输出格式与DPI、实际时间窗口、局部网络根/最大人数、年龄边界。display_seed独立于模型；当前布局完全确定，不需要随机抽样。

命令行导出：

```bash
python main.py export --run-dir results/<run_id> --output figures/<run_id> --figure-config configs/figures.yaml
```

Schelling四面板取窗口首个、实际中间和最后已记录步及真实动态曲线；提前停止时不创建step300。Covasim四面板展示疾病状态、传播网络、分层感染与年龄状态。网格采用固定色标/坐标；同一运行的时间序列轴范围保持一致。SVG文字/坐标轴保留矢量，100×100网格允许嵌入栅格层。不同run_id不得写入同一图形目录；同一日志、时间窗口和配置应生成相同图形数据与SVG。

实际示例与原始记录见experiments/validation/，图形是单次运行的过程描述，没有跨种子误差线、统计显著性或因果解释。已关闭记录表或缺失时间点会报错，不能将缺失数据绘制成零。
